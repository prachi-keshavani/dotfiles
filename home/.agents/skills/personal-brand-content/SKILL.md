# Personal Brand Content Builder

## Quick start

1. Ask the user which platform (TikTok, LinkedIn, or both) and format (talking head, text post, carousel, video script).
2. Pick a content pillar and signature series from REFERENCE.md.
3. Apply the Story → Lesson → Framework rotation based on the day/phase.
4. Generate a hook, script/outline, on-screen text, and CTA using the voice rules below.

## Voice rules

- Direct, honest, reflective. Write like you are explaining your career to someone who cares.
- Short, specific, slightly surprising hooks. Avoid generic motivational lines.
- Do not over-edit. Keep delivery human and unpolished enough to feel real.
- End with one thought to remember, not a hard sell.

## Workflows

### Generate a content idea

1. Identify the pillar (Career Growth, Opportunity Creation, Analytics/Data, Immigrant Journey).
2. Choose a signature series or a specific career moment from REFERENCE.md.
3. Determine the phase: Story (what happened), Lesson (what I learned), Framework (what I would tell someone else).
4. Output: hook, 3-5 bullet points, CTA.

### Write a TikTok script

1. Hook in the first 3 seconds (on-screen text + spoken line).
2. Body: 45-75 seconds, 1-2 short stories or 1 framework with 2-3 proof points.
3. Use simple on-screen captions. Cut pauses. Keep pace natural.
4. CTA: one reflective question or one-line takeaway.
5. Include a "B-roll suggestion" note if applicable.

### Write a LinkedIn post

1. Hook line (first 2 lines visible before "...see more").
2. Body: 3-5 short paragraphs with white space. Include one specific number or outcome.
3. Optional: add a 5-10 slide carousel outline if requested.
4. CTA: one question to start a conversation in comments.

### Repurpose one piece across platforms

1. Take the core insight from the original piece.
2. TikTok version: strip to one story + one lesson. Add energy and pace.
3. LinkedIn version: add context, numbers, and a professional framing. Invite discussion.
4. Carousel version: break the framework into 5-10 slides (1 concept per slide).
