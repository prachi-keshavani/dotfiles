### THE ACTUAL TEMPLATE (Content to Include in Download)

**Header Section**
```
[Full Name]
[City, UK] | [Email] | [LinkedIn URL] | [Portfolio/Website if applicable]

⚠️ NOTE: "Right to Work: Currently on [PSW/Graduate Visa], eligible for Skilled Worker sponsorship"

```

**Professional Summary (3-4 lines max)**
```
Data Analytics & CRM Specialist with 4+ years delivering measurable growth across SEO, paid media, and customer analytics. Built measurement frameworks for Samsung, grew e-commerce sales £8K→£25K/month, and optimized organic search performance +25%. Seeking to drive data-informed strategy in a visa-sponsoring environment.
```

**Key Rules for International Professionals:**
1. **Lead with outcomes, not duties.** "Grew organic traffic 25%" not "Responsible for SEO."
2. **Quantify everything.** Numbers transcend language and culture.
3. **Address the visa once, confidently.** Small note. Not a paragraph. Not an apology.
4. **Show UK market experience prominently.** Pixel Kicks, Digitas, BrightonSEO.
5. **Include tools stack.** SEMrush, GA4, Screaming Frog, Tableau, SQL, Python — make it scannable.

**Experience Section Format:**
```
Role | Company | Dates
→ Outcome 1 with metric
→ Outcome 2 with metric
→ Outcome 3 with metric
→ Tools used: [list]
```

Example:
```
CRM Data Analyst | Digitas (Samsung account) | 2023-2024
→ Built propensity models that improved campaign targeting efficiency by 18%
→ Delivered weekly dashboards to Samsung stakeholders with zero missed deadlines
→ Coordinated with 3 regional teams across tight timelines
→ Tools: SQL, Python, Tableau, Adobe Analytics
```

**Projects Section (Critical for Proof of Work)**
```
Technical SEO Audit | Personal Project
→ Crawled 50K+ URL site using Screaming Frog
→ Identified 340 broken links and 12 redirect chains
→ Documented findings in client-ready report format
```

**Education Section**
```
MSc Data Analytics | Brunel University London | 2022-2023
→ Dissertation: [Title if impressive/relevant]
→ Relevant modules: Advanced Analytics, Machine Learning, Data Visualization
```

### THE 10 FORMULAS (Content to Include in Download)

**Formula 1: The Outcome-First**
```
[Role] | [Specific metric you moved] | [Credibility marker]

Example:
"CRM Data Analyst | +18% campaign efficiency | Ex-Samsung, Digitas"
```

**Formula 2: The Credibility Stack**
```
[Role] | [Company 1], [Company 2] | [Specialty]

Example:
"SEO & Analytics Specialist | Red Bull, Pixel Kicks | Technical audits & measurement frameworks"
```

**Formula 3: The Problem-Solver**
```
I help [audience] achieve [outcome] through [method]

Example:
"I help B2B brands turn messy data into revenue decisions | SEO, CRM & analytics"
```

**Formula 4: The Specialization**
```
[Specific niche] | [Years experience] | [Notable metric]

Example:
"Cross-channel measurement | 4+ years | Connected SEO + PPC data for 6-figure accounts"
```

**Formula 5: The Aspirational**
```
[Current role] → [Target role] | [What you're building]

Example:
"Data Analyst → Analytics Lead | Building dashboards that change decisions, not just report them"
```

**Formula 6: The Immigrant-First (Your unique angle)**
```
[Role] | [Outcome] | [Journey hook]

Example:
"Data Analyst | +25% organic growth | First-gen immigrant, 8 years, 1,200 applications → finally sponsored"
```

**Formula 7: The Tool-Stack**
```
[Role] | [Primary tools] | [Outcome specialty]

Example:
"Analytics Specialist | GA4, SQL, Tableau, SEMrush | Technical SEO & CRM dashboards"
```

**Formula 8: The Mission-Driven**
```
[Role] on a mission to [specific mission]

Example:
"Data storyteller on a mission to make analytics accessible to non-technical teams"
```

**Formula 9: The Contrarian**
```
[Role] who believes [contrarian take]

Example:
"Analytics specialist who believes dashboards are useless without a story"
```

**Formula 10: The Minimalist (For senior roles)**
```
[Role] at [Company] | [One impressive metric]

Example:
"CRM Data Analyst at Digitas | Samsung account, 18% efficiency lift"
```

**BONUS: The 5-Minute Headline Audit**

Ask yourself:
1. Would a recruiter know what I do in 3 seconds?
2. Is there a number or outcome?
3. Does it sound like 500 other people?
4. Would someone want to click my profile?
5. Does it match the jobs I actually want?

If you answered NO to any of these, rewrite using one of the 10 formulas above.

## DELIVERY SYSTEM SETUP

### Option A: Manual DM (Start Here)
1. Post video with CTA ("Comment VISA for template")
2. When someone comments, copy-paste the DM message
3. Send Google Drive link or Notion page link
4. Track in a simple spreadsheet: Name | Comment Word | Date Sent | Follow-up?

### Option B: Automated (Scale Later)
1. Use ManyChat or similar for TikTok auto-DMs
2. Set trigger word ("VISA", "HEADLINE", "PLAN")
3. Auto-sends the DM with link
4. Captures email for your list

### Option C: Bio Link Tool (Best for Multiple Magnets)
1. Use Linktree, Beacons, or Stan Store
2. Create separate landing pages for each magnet
3. TikTok CTA becomes: "Link in bio for free template"
4. Captures email before download

**Recommended stack for starting:**
- **Now:** Manual DM + Google Drive link (zero cost)
- **At 1K followers:** ManyChat auto-DM ($15/month)
- **At 5K followers:** Stan Store or Carrd landing page + email capture
