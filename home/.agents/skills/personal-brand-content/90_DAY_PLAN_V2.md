# 90-Day Content Plan V2: Jess Ramos-Inspired Growth Engine

> This plan keeps your original Story → Lesson → Framework rotation from the 90-day Excel, but reworks hooks, adds new content types (tutorials, lists, opinions, BTS), and optimizes every CTA for saves, shares, and bio clicks.
>
> **Rule: Post 1x per day. Mix formats across the week.**

---

## Weekly Format Rotation

| Day | Format | Goal |
|-----|--------|------|
| Monday | Story (original rotation) | Comments + connection |
| Tuesday | Tutorial / Micro-skill | Saves + authority |
| Wednesday | Lesson (original rotation) | Comments + saves |
| Thursday | Resource List or Controversial Op | Shares + saves |
| Friday | Framework (original rotation) | Saves + action |
| Saturday | BTS / Process / Lifestyle | Trust + parasocial |
| Sunday | Repurpose best-performing post | Distribution + catch-up |

---

## Content Type Definitions

| Type | Description | Jess-Style Example |
|------|-------------|-------------------|
| **Story** | Personal career moment, raw and reflective | "I applied to 1,200 jobs before I understood how hiring works" |
| **Tutorial** | 60-90 second how-to with screen or demonstration | "How to read a GA4 report in 60 seconds" |
| **List** | Numbered resources, tools, or tips | "5 free tools I used to teach myself SEO during COVID" |
| **Opinion** | Contrarian take that sparks debate | "Applying to 1,200 jobs is a coping mechanism, not a strategy" |
| **BTS** | Behind-the-scenes of building your brand | "POV: You're watching me build a personal brand from 0" |
| **Lesson** | Extracted insight from a story | "Applications are not the same as a career strategy" |
| **Framework** | Actionable system or step-by-step | "3 things I would focus on if I had to start again" |
